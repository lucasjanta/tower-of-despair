# 🎮 Tower of Despair

> A turn-based combat roguelike about exploring a tower, making choices and trying to survive

## About the Game

**Tower of Despair** is a roguelike game developed with **Godot**.

You play as a mysterious Will, an entity capable of controlling different vessels. While exploring a tower, you can take over 2 characters and find items, relics and evolve your characters to get to the final boss.

This project is also an opportunity for me to improve my skills with turn-based combat, inventory systems and game art.
